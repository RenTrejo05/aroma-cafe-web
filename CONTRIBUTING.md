# Contributing

## Branch names
Use lowercase names with a type and short description:
- `feature/menu-page`
- `feature/login-form`
- `hotfix/footer-phone`

## Commit messages
Start each commit message with a type:
- `feat:` for new functionality
- `fix:` for bug corrections
- `style:` for layout or styling
- `docs:` for documentation

## Workflow
1. Create feature branches from `develop`.
2. Push the branch and open a pull request into `develop`.
3. Review the changes before merging.
4. Release tested changes from `develop` into `main`.
5. Create urgent production fixes from `main` and merge them back into both `main` and `develop`.
