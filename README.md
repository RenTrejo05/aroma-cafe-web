# Aroma Café Website

A small collaborative web-development project for practicing Git and GitHub workflows.

## Pages
- Home page
- Menu
- Login
- Contact

## Run locally
Open `index.html` in a modern browser. The site uses plain HTML, CSS, and JavaScript.

## Branch workflow
- `main`: stable release
- `develop`: integration branch
- `feature/*`: feature development
- `hotfix/*`: urgent production fixes
